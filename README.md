# 比特浏览器视频自动发布系统

基于比特浏览器(BitBrowser)的豆包视频抓取 + 抖音创作中心自动发布工具。提供 Web 控制台，支持多窗口、分组管理、每窗口独立视频源配置与定时批量发布。

## 功能特性

- **比特浏览器托管**：未运行时按配置路径自动拉起；自动同步现有窗口与分组
- **Web 控制台**：总览 / 窗口管理 / 发布任务 / 系统设置 / 运行日志 五页签
- **豆包聊天页抓取**：在指定窗口中打开豆包会话页，自动提取生成的最新视频直链（虚拟列表滚动加载、封面点击播放、上下文级网络监听三重保障），同时解析 Q/A 问答体文案
- **一号一窗一内容**：一个任务可绑定多个窗口，每个窗口配置**各自专属**的豆包聊天页链接，各自抓取、各自发布、独立去重
- **抖音自动发布**：通过 CDP 接管窗口 → 打开创作中心上传页 → 注入视频 → 等待上传与检测完成 → 自动填标题/简介/标签 → 点发布并处理确认弹窗 → 校验发布结果
- **定时调度**：cron 表达式（含预设），到点自动执行；支持单窗口每日上限
- **安全防护**：下载后校验 mp4 有效性，拦截接口误报的假链接；失败自动截图

## 环境要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10/11 |
| Python | 3.10+ |
| 比特浏览器 | 已安装（默认路径 `%LOCALAPPDATA%\Programs\bitbrowser\比特浏览器.exe`，可在页面修改） |

## 部署步骤

```bat
:: 1. 克隆项目
git clone https://github.com/ccrobo/bit-video-publisher.git
cd bit-video-publisher

:: 2. 安装依赖（建议先创建虚拟环境）
pip install -r requirements.txt
playwright install chromium

:: 3. 启动
python run.py
:: 或直接双击 start.bat
```

看到日志 `服务已启动，访问 http://127.0.0.1:8799/` 即启动成功。

> 首次运行会自动创建 `data\` 目录存放本地状态；该目录已在 `.gitignore` 中排除，不会被提交。

## 首次配置（只需一次）

1. **系统设置**：核对比特浏览器安装路径(exe)与本地 API 地址 → 保存
2. **总览**：点「同步窗口与分组」，拉取全部窗口和分组
3. **登录账号**（关键）：
   - 目标发布窗口：手动打开并登录一次 [creator.douyin.com](https://creator.douyin.com)（登录态持久化在该窗口）
   - 每个用于抓取的窗口：手动打开并登录一次 [doubao.com](https://www.doubao.com)

## 使用流程

```
新建任务(逐窗口填聊天页链接) → 窗口管理开启抓取开关 → 到点自动执行 / 手动「立即执行」→ 查看运行日志
```

### 新建任务要点（发布任务页）

| 配置项 | 说明 |
|---|---|
| 源类型 | 选「豆包聊天页(浏览器抓取)」 |
| 各窗口聊天页链接 | **必填**。选中目标分组/窗口后，为每个窗口填各自的豆包会话链接，如 `https://www.doubao.com/chat/xxxx` |
| 执行周期 cron | 预设或自定义，如 `0 9,15 * * *`(每天9点和15点) |
| 文案模板 / 话题标签 | `{title}` `{date}` 占位符；标签追加在简介末尾 |
| 单窗口日上限 | 0 为不限制 |

### 执行链路

```
逐个目标窗口:
  打开该窗口 → 打开它自己的聊天页 → 滚动加载并点击视频封面取直链
  → 下载最新视频(mp4校验) → 进入抖音创作中心 → 上传等待检测完成
  → 填Q/A文案+话题标签 → 点发布(自动确认弹窗) → 校验"发布成功" → 关闭窗口
```

## 数据位置

| 路径 | 内容 |
|---|---|
| `data\tasks.json` | 任务配置(**含各窗口聊天页链接，隐私数据**) |
| `data\window_configs.json` | 窗口开关与任务绑定 |
| `data\state.json` | 发布历史、去重记录、每日计数 |
| `data\downloads\<任务ID>\<窗口ID>\` | 已下载视频 |
| `data\screenshots\` | 发布失败自动截图(`fail-*.png`) |

> 以上均不入库。换机部署时如需保留任务配置，可手动拷贝 `data\*.json`。

## 常见问题

| 现象 | 处理 |
|---|---|
| 显示"比特浏览器 未运行" | 设置里核对 exe 路径；关闭拦截本地请求的系统代理 |
| 提示"未登录豆包" | 在对应窗口手动登录 doubao.com 后重试 |
| 视频 0 个 | 确认会话已生成过视频；调大「等待加载」；看日志是否有"已点击视频封面卡片" |
| "下载内容不是有效视频" | 正常防护(拦截假直链)，下轮自动重试真直链 |
| 上传/发布失败 | 查看 `data\screenshots\fail-*.png` 定位页面状态；多为抖音页面改版或弹窗变化 |
| GitHub 克隆/推送连接被重置 | 让 git 走本机代理：`git -c http.proxy=http://127.0.0.1:7890 push`(端口以你的代理软件为准) |
